# PRD剩余缺口补齐计划（第二轮）

## 1. 目标与范围

### 1.1 目标
- 仅补齐当前审计确认的 PRD 未完成项，达成“设备侧 + 应用侧 + 文档侧”一致闭环。
- 不新增与 PRD 无关的扩展能力，不改动既有可用链路。

### 1.2 本轮范围（必须完成）
1. App 补齐“最后更新时间”展示（PRD 7.2）。
2. App 补齐“设备列表”云端查询能力（PRD 7.1），替换仅本地手工维护模式。
3. 历史曲线接口补齐按时间范围查询参数（from/to/step）（PRD 7.5）。
4. 设备侧补齐投喂“执行超时失败”路径，保证事件与回执语义完整（PRD 11.2）。

### 1.3 非范围
- 不新增 OTA。
- 不新增系统级推送。
- 不改动现有 AP 配网接口协议（`/status`、`/scan`、`/config`）。

## 2. 任务拆解

### 任务A：App 显示“最后更新时间”
**涉及文件**
- `PetHome_APP/entry/src/main/ets/pages/Index.ets`
- `PetHome_APP/entry/src/main/ets/service/PetHomeApi.ets`

**实施要点**
1. 在顶部状态摘要中加入 `latest.ts` 的格式化展示。
2. `latest.ts` 为空或非法时展示 `-`。
3. 刷新失败时保持上次可用时间，不覆盖为当前时间。

**完成标准**
- 页面同时可见：在线状态、最后更新时间、固件版本。

---

### 任务B：App 设备列表改为云端来源
**涉及文件**
- `PetHome_APP/entry/src/main/ets/service/PetHomeApi.ets`
- `PetHome_APP/entry/src/main/ets/pages/Index.ets`
- `docs/Interface.MD`

**实施要点**
1. 新增设备列表查询方法（IoTDA 设备列表接口）。
2. 页面初始化优先拉取云端设备列表，失败时回退本地缓存列表。
3. 设备选择组件绑定云端返回列表，保留手工输入作为兜底入口。
4. 接口文档补充设备列表查询路径、请求头与返回字段。

**完成标准**
- 在不手工输入设备 ID 的情况下可看到云端设备列表并切换设备。

---

### 任务C：历史曲线按时间范围查询
**涉及文件**
- `PetHome_APP/entry/src/main/ets/service/PetHomeApi.ets`
- `PetHome_APP/entry/src/main/ets/pages/Index.ets`
- `docs/Interface.MD`

**实施要点**
1. 将 `getHistory(metric)` 升级为 `getHistory(metric, from, to, step)`。
2. 页面新增时间范围参数输入（起止时间、粒度 step）。
3. 查询时优先按输入范围拉取并渲染，失败时可回退本地缓存。
4. 同步更新接口文档中的参数定义与示例。

**完成标准**
- 可按指定时间范围获取并绘制曲线；参数变更会触发重新查询。

---

### 任务D：投喂超时失败路径补齐（设备侧）
**涉及文件**
- `PetHome_Device/src/actuator_manager.h`
- `PetHome_Device/src/actuator_manager.cpp`
- `PetHome_Device/src/main.cpp`
- `docs/Interface.MD`

**实施要点**
1. 在投喂流程中增加“动作执行超时”状态判定。
2. 超时时必须：
   - 上报 `FEED_FAILED` 事件；
   - 命令回执返回 `FAILED`（互锁拒绝仍返回 `REJECTED`）。
3. 保证 `request_id/result/reason/ts` 字段完整，语义与文档一致。
4. 增加必要的状态复位，避免后续投喂流程卡死。

**完成标准**
- 人工制造超时时，App 与云端均可观测到 `FEED_FAILED` + `FAILED` 回执。

## 3. 联调与验收

### 3.1 回归清单
1. 设备列表：云端可拉取并切换目标设备。
2. 状态头：显示在线/离线、最后更新时间、固件版本。
3. 历史查询：按 from/to/step 查询并绘制温湿度/VOC 曲线。
4. 投喂异常：互锁为 `REJECTED`；超时为 `FAILED` 且有 `FEED_FAILED`。

```bash
python -m platformio run -d PetHome_Device -e esp32s3
```
