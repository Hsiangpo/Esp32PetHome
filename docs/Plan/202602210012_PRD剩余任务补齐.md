# PRD剩余任务补齐计划

- 计划文件: docs/Plan/202602210012_PRD剩余任务补齐.md
- 更新时间: 2026-02-21 00:12
- 范围: PetHome_Device、PetHome_APP、docs

## 1. 目标

按 docs/PRD.MD 补齐未闭环项，达到代码实现、页面入口、文档口径、验收证据四项一致。

## 2. 剩余任务(P0)

### 2.1 设备端 PetHome_Device

1. 设置模式参数修改闭环
- 在 OLED 设置页实现参数项切换、数值增减、2 秒确认保存、5 秒恢复默认。
- 覆盖至少以下参数: food_low_threshold_g、feed_target_g、light_on_threshold、light_off_threshold、voc_on_threshold、voc_off_threshold、temp_high_threshold_c、temp_low_threshold_c、hum_high_threshold_rh、hum_low_threshold_rh。

2. OLED 告警历史展示
- 增加最近 10 条事件环形缓冲。
- 支持在 OLED 中翻阅事件摘要(时间、类型、级别)。

3. 事件语义收敛
- 事件类型严格对齐 PRD: LOW_FOOD、LOW_WATER、WATER_REFILL_FAILED、FEED_FAILED、SENSOR_FAULT、WIFI_OFFLINE、CLOUD_OFFLINE。
- 清理语义不一致事件(例如风扇运行超时不再混入传感器故障)。

4. 中文化收口
- 注释、提示字符串统一为客观中文。
- 清理英文解释性注释。

### 2.2 应用端 PetHome_APP

1. 设备列表持久化
- 将设备 ID 列表保存到本地持久化存储。
- 应用重启后自动恢复设备列表与当前选中设备。

2. 数据来源口径统一
- 明确云端优先/本地兜底，或本地聚合演示的单一口径。
- 代码行为与 docs/Interface.MD、docs/PRD.MD 完全一致，不出现文档与实现冲突。

3. 历史曲线可视化
- 将当前文本点位列表改为可视化曲线。
- 至少支持温度曲线，建议增加湿度和 VOC 切换。

4. 文案收口
- 事件类型和命令回执三态(OK、REJECTED、FAILED)全部提供稳定中文展示。

### 2.3 文档 docs

1. docs/Interface.MD
- 同步命令、回执、事件、AP 配网接口和字段定义。

2. docs/HuaweiCloud.MD
- 同步服务 ID、命令名、属性字段、事件字段和当前有效参数。

3. docs/Acceptance_Checklist.MD
- 增补以下验收项:
- 设置模式改阈值并重启保持
- OLED 告警翻阅
- 设备列表重启保留
- 历史曲线可视化

## 3. 实施顺序

1. 设备端设置模式参数编辑。
2. 设备端 OLED 告警历史与事件语义收敛。
3. 应用端设备列表持久化。
4. 应用端历史曲线可视化与文案收口。
5. 文档同步更新。
6. 全量联调与证据归档。

## 4. 提交前门禁

1. python scripts/code_guard.py
2. python -m platformio run -d PetHome_Device -e esp32s3
3. App 测试执行结果(至少 PetHomeValidators.test.ets)

## 5. 回传材料

1. 变更文件清单(按设备端/应用端/文档分组)。
2. 关键截图与日志:
- AP 配网
- 命令三态回执
- 补水失败锁定与人工解除
- OLED 告警翻阅
- 历史曲线页面
3. 门禁命令输出摘要。
