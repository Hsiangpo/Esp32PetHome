# Servo PWM Feed Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把设备端投喂控制从简单高低电平输出升级为标准舵机 PWM 的非阻塞三阶段动作，同时保持现有端云接口兼容。

**Architecture:** 在 `ActuatorManager` 内新增舵机 PWM 输出与投喂阶段机状态，`StartFeed()` 负责启动动作，`Loop()` 负责推进“开门 -> 停留 -> 回位”。通过在 `PIO_UNIT_TESTING` 下引入轻量硬件抽象，使停留时长映射和阶段推进可在 `native` 环境做单测。

**Tech Stack:** PlatformIO、Arduino、ESP32 LEDC PWM、Unity 原生测试。
