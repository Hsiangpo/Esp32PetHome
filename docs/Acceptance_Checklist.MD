# 验收清单（端到端 / 可截图用于论文）

本文档用于“设备侧 + 云端 + 应用侧”的一步步验收与截图点位记录，便于课设答辩/论文实验章节复现。  
本文与 `docs/PRD.MD`（v0.3）和 `docs/TECH.MD`（v1.0）对齐。

> 安全提示：验收与截图时请遮挡 AK/SK、设备密钥、Wi-Fi 密码等敏感信息。

---

## 0. 环境准备

- [ ] 已在华为云 IoTDA 创建项目（`project_id`）与设备（`device_id`）
- [ ] 已按 `docs/Wiring_Guide.MD` 完成接线，并确认继电器触发电平、液位输入电平、I2C 供电与共地要求
- [ ] 设备固件已烧录，可启动 AP 配网（参考 `docs/TECH.MD`）
- [ ] HarmonyOS App 工程可运行（`PetHome_APP/`，API 17）
- [ ] 设备与手机可访问 IoTDA Endpoint

## 4. 远程控制命令（手动）

**操作：**

- [ ] 在 App 依次执行：LED 开关、风扇开关、水泵开关
- [ ] 手动触发一次投喂（`feed_once`）

**预期：**

- [ ] 命令有明确回执：`OK` / `REJECTED` / `FAILED`
- [ ] 执行成功后，影子/App 状态与实际设备动作一致
- [ ] 当前代码版投喂动作可通过 `servo_active` 状态位与实体舵机动作共同验证

## 7. 自动投喂（开环）

**操作：**

- [ ] 让 `food_g` 低于 `food_low_threshold_g`（或通过手动触发）执行投喂

**预期：**

- [ ] 当前固件版以舵机执行“打开 -> 停留 -> 回位”三阶段动作，且总时长不超过 `feed_max_run_ms` 作为开环投喂验收依据
- [ ] `feed_target_g` 改变后，舵机在打开角度的停留时间应随之变化
- [ ] 回执可见；失败时产生 `FEED_FAILED`
- [ ] 投喂判定不依赖重量增量闭环

## 13. 常见问题（快速定位）

- 设备不在线：优先检查 Wi-Fi、IoTDA 设备三元组、时间同步是否正常
- 命令超时：检查设备是否离线、是否触发互锁、是否执行器超时保护
- App 无数据：检查 `GET /v5/iot/{project_id}/devices/{device_id}/shadow` 与 `GET /v5/iot/{project_id}/devices/{device_id}` 返回是否正常
- VOC 异常：检查 `tvoc_ppb -> voc_index` 映射是否按约定生效
