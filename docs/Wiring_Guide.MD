# 硬件选购与接线指南（Wiring Guide）

本文档按仓库当前设备端代码真实行为编写，用于指导最小硬件采购、逐模块接线与首次联调。

接线与电平口径以以下代码为准：
- `PetHome_Device/include/board_pins.h`
- `PetHome_Device/src/sensor_manager.cpp`
- `PetHome_Device/src/actuator_manager.cpp`
- `PetHome_Device/src/button_manager.cpp`
- `PetHome_Device/src/display_manager.cpp`

---

## 1. 先看结论

- 当前固件已经稳定定义了全部 GPIO：I2C=`GPIO8/9`，HX711=`GPIO16/17`，水位=`GPIO18`，舵机控制=`GPIO4`，水泵继电器=`GPIO5`，风扇继电器=`GPIO6`，LED=`GPIO7`，按键=`GPIO15`。
- 当前固件对 `GPIO4` 已输出**标准 RC 舵机 PWM**：频率 `50Hz`，默认按 `500us ~ 2400us` 脉宽范围映射角度；投喂动作采用“打开 -> 停留 -> 回位”的非阻塞三阶段流程。代码内部继续使用 `servo_active` 表示舵机动作进行中。
- 当前固件对 `GPIO5/GPIO6/GPIO7` 采用 `digitalWrite(HIGH)` 表示开启，因此采购时必须保证：
  - 继电器模块为**高电平触发**；
  - LED 为**3.3V 低功耗直驱方案**，不能直接买“仅支持 5V 常亮输入”的灯条模块。
- 当前固件将 `GPIO18` 配置为 `INPUT_PULLUP`，并以读取到 `LOW` 判定低水位，因此液位传感器输出到 `GPIO18` 的电平必须满足 ESP32 3.3V GPIO 约束。

## 4. 逐模块针脚对针脚接线

## 4.1 I2C 总线：SHT31、SGP30、BH1750、OLED 共线

所有 I2C 模块统一采用同一组总线：

| 模块引脚 | 接到 ESP32-S3 |
| --- | --- |
| `VCC` | `3V3` |
| `GND` | `GND` |
| `SDA` | `GPIO8` |
| `SCL` | `GPIO9` |

说明：
- 当前工程没有做 I2C 电平转换，因此**I2C 模块统一使用 3.3V 供电**，避免板载上拉电阻把 `SDA/SCL` 拉到 5V。
- 当前代码默认地址口径：
  - `SHT31`：固定按 `0x44` 初始化；
  - `OLED SSD1306`：固定按 `0x3C` 初始化；
  - `SGP30`、`BH1750`：按库默认地址初始化。
- 采购 OLED 时应选择 4 针 I2C 版本，不采购 SPI 版本。

## 4.2 HX711 与称重片

### HX711 模块接主控

| HX711 引脚 | 接到 ESP32-S3 |
| --- | --- |
| `VCC` | `5V` |
| `GND` | `GND` |
| `DT` / `DOUT` | `GPIO16` |
| `SCK` | `GPIO17` |

### 称重片接 HX711

常见 4 线称重片接线如下；若卖家线色不同，以卖家丝印或说明书为准：

| 称重片线 | 接到 HX711 |
| --- | --- |
| 红线 | `E+` |
| 黑线 | `E-` |
| 绿线 | `A+` |
| 白线 | `A-` |

说明：
- 当前代码在启动时会执行 `hx711_.tare()`，因此**首次上电去皮时秤台必须为空载**。
- 当前代码默认 `set_scale(400.0f)` 仅是演示比例，实际论文演示前仍需根据实物做一次标定。

## 4.3 液位传感器 XKC-Y25

### 目标口径

- 代码只读取数字状态，不读取模拟量；
- `GPIO18` 被配置为 `INPUT_PULLUP`；
- 程序判定规则：读取到 `LOW` 即为低水位。

### 接线原则

| 传感器引脚 | 接线要求 |
| --- | --- |
| `VCC` | 按所购模块要求供电，常见为 `5V` |
| `GND` | 与 ESP32 共地 |
| `OUT` | 接 `GPIO18`，且输出到 GPIO 的高电平不得超过 `3.3V` |

说明：
- 若所购 XKC-Y25 为**开漏 / 开集电极输出**，可直接接 `GPIO18`，由 ESP32 内部上拉维持高电平。
- 若所购 XKC-Y25 为**推挽 5V 输出**，则**禁止**直接接入 `GPIO18`，必须加分压、电平转换或光耦隔离。
- 液位安装高度决定 `LOW` 触发点，软件不会自动换算为百分比。

## 4.4 水泵与风扇继电器

推荐使用一个两路继电器模块，若现场只能买到单路继电器，也可以用两个单路模块替代。

### 继电器控制侧接主控

| 继电器模块引脚 | 接线 |
| --- | --- |
| `VCC` | `5V` |
| `GND` | `GND` |
| `IN1` | `GPIO5`（水泵） |
| `IN2` | `GPIO6`（风扇） |

### 继电器负载侧接法

#### 水泵回路

| 回路位置 | 接线 |
| --- | --- |
| 电源正极 `5V+` | 继电器 `COM1` |
| 继电器 `NO1` | 水泵正极 |
| 水泵负极 | 电源地 `GND` |

#### 风扇回路

| 回路位置 | 接线 |
| --- | --- |
| 电源正极 `5V+` | 继电器 `COM2` |
| 继电器 `NO2` | 风扇正极 |
| 风扇负极 | 电源地 `GND` |

说明：
- 当前代码逻辑固定为 `HIGH=开`，因此继电器必须采购**高电平触发**版本。
- 继电器负载端统一使用 `NO`（常开）端，不使用 `NC`（常闭）端。
- 若现场仅能买到低电平触发继电器，则需修改固件后再接线，本文档不覆盖该变体。

## 4.5 LED 指示灯

| 元件引脚 | 接线 |
| --- | --- |
| `GPIO7` | 串联 `220Ω` 电阻后接 LED 正极 |
| LED 负极 | `GND` |

说明：
- 当前代码直接 `digitalWrite(GPIO7)`，适合驱动单颗低功耗 LED。
- 不建议在当前代码下直接接 5V 灯带、5V 大功率灯板或需独立驱动的 LED 模块。

## 4.6 用户按键

| 按键引脚 | 接线 |
| --- | --- |
| 一端 | `GPIO15` |
| 另一端 | `GND` |

说明：
- 当前代码使用 `OneButton(board_pins::kUserButton, true, true)`，即低电平有效并启用内部上拉。
- 按键不能接到 `3V3`，否则按下时不会形成有效低电平。

## 4.7 舵机 `GPIO4`

### 当前代码真实行为

- `GPIO4` 使用 `LEDC` 输出标准 RC 舵机 PWM；
- 默认频率为 `50Hz`；
- 默认脉宽映射范围为 `500us ~ 2400us`；
- 单次投喂流程为：舵机转到 `70°`，按 `feed_target_g` 映射结果停留，再回到 `0°`；
- `feed_max_run_ms` 仍作为整次投喂动作的总超时保护。

### 舵机接线

| 舵机线色 / 引脚 | 接线 |
| --- | --- |
| 信号线（常见橙 / 黄） | `GPIO4` |
| 电源正极（常见红） | `5V` |
| 地线（常见棕 / 黑） | `GND` |

说明：
- 舵机电源必须与主控共地；
- 舵机电流不能从 `3V3` 取电；
- 若使用 `MG90S` 金属齿舵机，建议优先给舵机单独 5V 电源再共地。

### 投喂量映射规则

`feed_target_g` 不直接控制角度，而是映射为舵机打开后的停留时长：
- 基础停留 `300ms`；
- 每 `10g` 额外增加 `120ms`；
- 上限 `1500ms`。

示例：
- `10g` -> `420ms`
- `50g` -> `900ms`
- `200g` -> `1500ms`（封顶）

## 5. 供电拓扑与共地要求

推荐供电方式如下：

| 供电对象 | 推荐电源 |
| --- | --- |
| ESP32-S3 主控板 | USB 5V |
| I2C 传感器 / OLED | 主控板 `3V3` |
| HX711 | `5V` |
| 继电器模块 | `5V` |
| 水泵 / 风扇 | `5V` 独立负载电源或与继电器同源 5V |

硬性要求：
- 所有电源地必须共地；
- 水泵、风扇、继电器线圈不能从 `3V3` 取电；
- 单电源方案建议至少 `5V / 3A`；
- 任何进入 ESP32 GPIO 的信号都不得高于 `3.3V`。

## 6. 上电前防呆检查清单

- `GPIO5/GPIO6` 所接继电器确认为高电平触发；
- `GPIO18` 输入电平已确认不超过 `3.3V`；
- I2C 模块已统一接 `3V3`，不存在把 `SDA/SCL` 上拉到 `5V` 的情况；
- LED 串联了限流电阻；
- 按键为 `GPIO15 -> GND` 接法；
- 水泵、风扇、电源与主控已共地；
- HX711 去皮前秤台为空载；
- 舵机已接 `GPIO4` 且供电稳定，共地无误。

---

## 7. 首次联调顺序

1. 仅连接 ESP32-S3、OLED、按键，确认能正常启动并切页。
2. 接入 SHT31、SGP30、BH1750，确认 I2C 设备都能正常出数。
3. 接入 HX711 与称重片，空载上电完成去皮，再放标准砝码做比例校正。
4. 接入液位传感器，先只观察 `GPIO18` 逻辑变化，再联调自动补水。
5. 接入继电器、水泵、风扇，验证 `GPIO5/GPIO6` 的高电平吸合逻辑。
6. 最后接入舵机并验证单次投喂动作：打开、停留、回位三阶段完整执行。

---

## 8. 文档与代码同步规则

- 若 `board_pins.h` 变更 GPIO，必须同步修改本文档。
- 若后续调整舵机角度、脉宽范围或 `feed_target_g` 到停留时长的映射规则，必须同步修改本文档与 `docs/PRD.MD`。
- 若继电器逻辑从高电平触发改为低电平触发，必须同步修改本文档和 `docs/PRD.MD`。
