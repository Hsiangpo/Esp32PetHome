# 硬件选购与接线指南（Wiring Guide）

本文档给出课设最小可运行硬件清单与接线映射，面向快速搭建与联调。  
接线以 `PetHome_Device/include/board_pins.h` 为准。

---

## 1. 最小硬件清单（精简）

| 类别 | 型号建议 | 数量 | 说明 |
| --- | --- | --- | --- |
| 主控板 | ESP32-S3 DevKitC | 1 | 核心控制器 |
| 温湿度传感器 | SHT31-DIS | 1 | I2C |
| 空气质量传感器 | SGP30 | 1 | I2C |
| 光照传感器 | BH1750 | 1 | I2C |
| 称重模块 | HX711 + 称重片 | 1 套 | DT/SCK 接口 |
| 液位传感器 | XKC-Y25 非接触 | 1 | 数字输入 |
| OLED | SSD1306 0.96寸 I2C | 1 | 本地显示 |
| 舵机 | SG90 / MG90S | 1 | 投喂执行 |
| 继电器模块 | 5V 单路继电器 | 2 | 水泵与风扇控制 |
| 水泵 | 5V 微型水泵 | 1 | 补水 |
| 风扇 | 5V 小风扇 | 1 | 排风 |
| LED 灯 | 5V LED 模块 | 1 | 照明 |
| 按键 | 轻触按键 | 1 | 本地交互 |
| 电源 | 5V/2A 适配器 | 1 | 舵机/水泵建议独立供电并共地 |

## 2. 引脚映射

| 功能 | ESP32-S3 引脚 | 备注 |
| --- | --- | --- |
| I2C SDA | GPIO8 | SHT31/SGP30/BH1750/OLED 共线 |
| I2C SCL | GPIO9 | SHT31/SGP30/BH1750/OLED 共线 |
| HX711 DT | GPIO16 | 称重数据线 |
| HX711 SCK | GPIO17 | 称重时钟 |
| 水位传感器数字输出 | GPIO18 | `LOW` 表示低水位 |
| 舵机控制 | GPIO4 | PWM 控制 |
| 水泵继电器 | GPIO5 | 高电平吸合（按模块实际可调整） |
| 风扇继电器 | GPIO6 | 高电平吸合（按模块实际可调整） |
| LED 照明 | GPIO7 | 直驱或经驱动 |
| 用户按键 | GPIO15 | 上拉输入 |

---

## 3. 关键接线说明

1. **I2C 总线并联**  
SHT31、SGP30、BH1750、SSD1306 全部接到 GPIO8/9，确保地址不冲突。

2. **执行器供电**  
舵机、水泵、风扇建议由独立 5V 供电，不直接从 ESP32 3.3V 取电。  
主控与执行器电源必须共地（GND 相连）。

3. **继电器与感性负载保护**  
水泵/风扇通过继电器控制，继电器板应带光耦与反灌保护。

4. **液位传感器逻辑**  
XKC-Y25 输出接 GPIO18，按程序约定 `LOW` 为低水位触发。

---

## 4. 上电前检查清单

- 电源极性确认无误
- GND 共地已连接
- 继电器常开/常闭接法与程序逻辑一致
- 舵机信号线与电源线未接反
- I2C 设备地址无冲突，线序 SDA/SCL 正确

---

## 5. 首次联调建议顺序

1. 仅连接 ESP32 + OLED，确认能启动  
2. 接入 I2C 传感器，确认数据读取正常  
3. 接入液位和称重模块  
4. 最后接入舵机/水泵/风扇/LED，验证互锁策略
